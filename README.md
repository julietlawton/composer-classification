# Composer Classification
The goal of this project was to build a CNN-LSTM model capable of accurately classifying a score of music as belonging to one of four classical music composers - Bach, Beethoven, Chopin, or Mozart. The dataset used for this project was the MIDI Classic Music dataset from Kaggle (Fedorak, 2018), which contains musical scores for 175 classical music composers represented as MIDI files. This was the final project for the course **AAI 511: Neural Networks and Deep Learning**.
